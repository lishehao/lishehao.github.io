One program instead of edited scripts

Written to replace the hand-edited Python scripts behind frequency-response measurements; saves MAT, TXT and CSV results with plots.

Check what the instruments did

More than a chatbot

One premise becomes a cast, a player role with a private objective and an opening scene, then a 12-turn story of choices and free-form actions.

State that is kept

Story templates, sessions and messages are stored in SQLite behind typed API contracts, so a finished run can be replayed.

A run you can inspect

A reviewer view shows the state behind each turn. The advisor can read the run but cannot change the story. Built with coding agents.

Start now or wait

Follow request A into a server and choose whether it starts at once or waits briefly so others can join its round.

Same arrivals, two strategies

Replay exactly the same requests under the other strategy and compare your own finish time with the time to finish the whole group.

A model you can read

Each round takes 1900 + 300 × batch size simulated milliseconds, an illustrative rule that makes fixed overhead visible. It runs in the browser with no AI service.
